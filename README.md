# Quant Stock Analysis System

A quantitative stock market analysis project built using Python, Machine Learning, and Financial Analytics concepts.

---

## Features

- Live stock market data fetching using Yahoo Finance API
- 50-Day and 200-Day Moving Average Analysis
- Stock trend visualization
- Machine Learning based prediction using Linear Regression
- Financial data analytics and visualization

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- yFinance
